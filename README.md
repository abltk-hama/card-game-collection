# ひとやすみカード部

スマートフォンの縦画面を中心に遊べるTypeScript製カードゲーム集。神経衰弱・ババ抜き・カラーマッチ（UNO風）・大富豪・ジンラミー・七並べ・ポイント七並べをAIと対戦できます。

## 開発

Node.js 22.18以降とpnpm 11.19.0を使用します。

````sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
````

開発URLは `http://127.0.0.1:5173/card-game-collection/`。画面・ルール・AIの処理はブラウザー内で完結します。

## ゲーム

- 神経衰弱：24枚、AIと1対1。公開済みカードをAIが記憶します。
- ババ抜き：53枚、自分＋AI3人。最後にジョーカーが残った人が負け。
- カラーマッチ：自分＋AI3人、各7枚。独自カードとエクスパンドを個別に有効／無効にできます。対象カードの25％に＋を付与し、ワイルドで全体のOn/Off切り替え、数字の追加面、ドロー返し、シールド反射に対応。[細則](docs/uno-expand.md)を参照してください。
- 大富豪：自分＋AI3人、52枚・ジョーカーなし。革命・8切り・都落ち・順位に応じたカード交換、ラウンド継続に対応。手札を複数選択し「出す」で確定します。
- ジンラミー：AIと1対1、各10枚、100点先取。ノック・ジン・アンダーカット・付け札に対応。組と残り点数は自動判定し、カード選択で捨てた後の点数を確認できます。詳しい細則は [ジンラミーのルール](docs/gin-rummy.md) を参照してください。
- 七並べ：自分＋AI3人、52枚・ジョーカーなし。7を自動配置して♦7の持ち主から開始。パス3回まで、4回目で脱落して残りの手札を場に置きます。離れて置かれたカードの隣にも出せます。手札をなくした順に上位、脱落順に下位を確定し、最後の1人は残った順位で終了します。出せるカードがあってもパス可能、AとKはつながりません。
- ポイント七並べ：通常七並べとは別の独自ゲーム。7側につなぐと＋2点、A/K側から未接続の並びへ出すと＋1点、パス－1点。パス1周後は出せる人が必ず配置。最後の1人に最終1手を設け、残り手札を減点して得点順で勝負します。5種類の特殊カードを全員に1枚配布し、次ラウンドは最下位だけ追加1枚を選択。累計点を引き継いで遊べます。[ルール](docs/point-sevens.md)・[公平さの初回調査](docs/point-sevens-fairness.md)を参照してください。

交換は相手と残りの手札を交換、シールドはドローを1回防御、全員ドローは自分以外が1枚引きます。カード効果処理後に手札0枚の人が勝利。交換を最後のカードとして使い、相手の手札が0枚になった場合は相手の勝利です。エクスパンド無効では+2・+4の積み重ねはありません。エクスパンド有効ではOn中の＋ドロー4だけで累積攻撃を返せます。UNO宣言・チャレンジはありません。詳しい説明は各ゲームの「遊び方」を参照してください。

### 大富豪のルール

通常は3が最弱、2が最強。同じ数字を1〜4枚出し、場と同じ枚数でより強い数字を出します。4枚で革命し強さが逆転、再革命で戻ります。8切りは場を流して出した人から再開（あがった場合は次の未終了者）。パスは場が流れるまで復帰できません。最後に出した人以外が全員パスしたら場が流れます。

前回の大富豪が最初にあがれなければ即都落ちして最下位確定。次ラウンドは大富豪↔大貧民で2枚、富豪↔貧民で1枚を同時交換。下位は通常の強さ順で最強カード、上位は任意カードを渡します。AI上位は自分の弱いカードを渡します。初回はダイヤ3の持ち主から、以降は前回の大貧民から開始し、革命状態は毎ラウンドリセットします。階段・縛り・11バック・あがり禁止はありません。

## GitHub Pages

`vite.config.ts` は `/card-game-collection/` を公開パスに設定しています。

1. GitHubのリポジトリで **Settings → Pages → Source → GitHub Actions** を選択します。
2. `main` にpushすると `.github/workflows/pages.yml` がテスト・ビルド・公開を実行します。
3. 公開成功後の予定URL：`https://abltk-hama.github.io/card-game-collection/`。

公開設定・push・リモートでの実行が完了するまでは公開済みではありません。

## 制約

途中保存・オンライン対戦は初期版に含みません。画面を再読み込みするとゲームがリセットされます。カラーマッチは独自のルール・表示で作成したUNO風ゲームです。
