# ジンラミーのルール

自分とAI ソラの1対1、52枚・ジョーカーなし。各10枚で開始し、累計100点以上を先に取った人が勝利します。

## 組と残り点数

- 同じ数字3〜4枚、または同じスートの連続3枚以上で組を作ります。
- Aは1。A-2-3は組、Q-K-Aは組になりません。1枚を複数の組には使えません。
- 組に含まれないカードの点数はA=1、2〜10=数字、J/Q/K=10です。
- 組は残り点数が最小になる配置を自動判定します。ノック側の同点配置は手札順と候補順で決めます。

## 手番

初回の配り手はランダム。最初の表札は配り手でない人、配り手の順に取るか見送ります。双方見送りなら配り手でない人が山札から引いて開始します。

以降は山札か捨て札の最上段から1枚引き、1枚選んで捨てます。捨て札から取ったカードは同じ手番に捨て直せません。選択すると捨てた後の残り点数を予告します。「捨てる」は通常の手番継続、「捨ててノック／ジン」はラウンド終了です。

## ラウンドの決着と得点

|決着|条件と得点|
|---|---|
|ノック|捨てた後の残り点数が1〜10。相手より少なければ差分を獲得|
|アンダーカット|相手の残り点数がノック側以下。相手が差分＋25点を獲得。同点でも25点|
|ジン|捨てた後の残り点数が0。相手の残り点数＋25点を獲得|

通常のノックでは相手の組と、ノック側の組への付け札を合わせて最小の残り点数を計算します。付け札は同数字の4枚目、連番の両端への追加で、連鎖も可能です。ジンには付け札できません。

山札が2枚になった手番でノック・ジンしなければ無得点終了し、同じ配り手で配り直します。得点が発生した次ラウンドは配り手を交代します。累計得点は次ラウンドへ引き継ぎます。ビッグジン・ラウンド勝利数ボーナスなどはありません。

AIの判断材料は自分の手札と公開捨て札です。相手の非公開手札や山札の中身は参照しません。

ルール確認の参考：[Gettysburg College Gin Rummy Rules](https://cs.gettysburg.edu/~tneller/games/ginrummy/eaai/gin-rummy-rules.pdf)。得点方式・組の自動確定など、このページの細則を本ゲームの仕様とします。
