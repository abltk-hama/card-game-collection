# ポイント七並べの公平さ：初回調査

実施日：2026-10-03。承認済みの候補ルールを実装して測定。測定に基づく得点補正や開始順変更はまだ行っていません。

## 方法と再現

固定seed 20261003から1,200配札を作り、同じ配札を4つの開始位置で対戦させ、3つのAI方針で比較しました。各方針4,800対戦、合計14,400対戦。各対戦は全員同じ方針です。4開始位置は同じ配札の反復であり、14,400の独立配札ではありません。

- `strategic`：ゲームに実装したAI。＋2点を優先し、条件付きで待つ。
- `always_place`：実装AIの配置評価は同じで、合法手があれば必ず配置。
- `random_place`：合法手をランダムに選び、出せるカードがあれば配置。

````sh
node --experimental-strip-types scripts/point-sevens-fairness.ts
````

機械可読データは [point-sevens-fairness.json](point-sevens-fairness.json)。`seat`は開始者を1番手として4開始位置をまとめた値、`actualDiamondStartSeat`は実際の♦7開始だけの値です。数字ごとの`meanCardCredit`は配置点、最後に残った場合は－1点を割り当てた平均で、パス減点を各カードへ割り振っていません。

## 手番順の影響

開始位置を変えた4,800対戦での勝率：

|方針|1番手|2番手|3番手|4番手|
|---|---:|---:|---:|---:|
|実装AI|18.8%|23.2%|26.9%|31.1%|
|必ず配置|18.4%|23.5%|26.8%|31.2%|
|ランダム配置|24.5%|24.5%|26.1%|24.8%|

実装AIでは同じ手札（元の♦7所有者）を1番手と4番手にした点数差は平均－1.11点。配札ごとの対応のある差から求めた近似95%区間は－1.20〜－1.02点です。必ず配置でも平均－1.15点、ランダムでも－0.46点でした。

実際の♦7開始1,200対戦では、実装AIの勝率は1番手13.0%、2番手26.3%、3番手30.1%、4番手30.7%。ここには♦7を持っている配札条件も含まれます。ランダム配置では同順に26.6%、23.7%、26.6%、23.2%です。

観測：＋2点優先の方針では後手有利が目立ちます。推論として、他の人が7側を開いてから手番が来る利益と、序盤のパス減点が影響している可能性があります。ランダム配置では差が縮むため、ルールとAIの組み合わせによる結果であり、人間同士や最適戦略でも同じ差になるとは断定できません。

## 3・4・10・Jを多く持つ手札

実装AI、4開始位置の集計。数字ごとの枚数は配札時の手札で数えます。

|3・4・10・Jの合計枚数|手札観測数|平均点|勝率|
|---|---:|---:|---:|
|0〜2枚|2,776|23.15|24.7%|
|3〜4枚|9,564|23.25|25.9%|
|5枚以上|6,860|23.09|23.8%|

この集計では大量に持つ手札に大きな点数差は見られませんでした。ただし、他の数字・7の枚数・開始位置も同時に変わる条件付き集計で、数字の因果効果ではありません。ランダム配置では0〜2枚の勝率27.1%、5枚以上22.7%となり、方針によって差が変わります。

カードごとの配置点・残り手札減点の平均（実装AI）は、A/Kが約1.53〜1.55点、3/Jが約1.89〜1.90点、4/10が約1.96点、6/8がほぼ2点でした。今回の方針では、低い配置点になりやすいのはA/K側です。

## 7の枚数と終盤

実装AI、4開始位置の集計では、7が0枚の手札は平均23.90点・勝率35.2%、1枚は23.26点・23.8%、2枚以上は22.19点・15.1%。7の＋2点を付けても、7を多く持つ手札の不利な関連が残っています。手札の構成・開始条件・配置方針との交絡があるため、初期得点だけの効果ではありません。ランダム配置では同じ7枚数順に勝率19.0%、26.8%、29.0%と逆転します。

実装AIでは最初にあがった人が得点でも勝つ割合48.9%、最後の1人が勝つ割合9.2%。最後の最終手番後の残りは平均0.32枚でした。14,400対戦はすべて終了し、実装AIの最長は75手番。通常のAI対戦では全員連続パスによる強制配置への移行は0回でしたが、常時パスを試みる別テスト100対戦で強制配置と終了を検証しています。

## 判断

「3・4・10・Jが一律に大きく不利」とはいえません。一方、＋2点優先のAIでは開始順と7の枚数に偏りが見られ、公平と判定する根拠はありません。通常七並べとの公平さの直接比較、人間の戦略・混合AI対戦、実機での試遊は未実施です。
