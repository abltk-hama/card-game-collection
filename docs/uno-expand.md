# カラーマッチのエクスパンド

自分＋AI3人、各7枚。独自カード（交換・シールド・全員ドロー）とエクスパンドは別々に有効／無効を選びます。エクスパンド設定の初期選択は有効、対戦の効果状態はOffから開始します。

## ＋の付与

数字・ワイルド・ドロー2・ドロー4・スキップ・リバース・シールドに、各カード独立25％で＋を付与。交換・全員ドローは対象外。枚数は108枚、独自カード有効なら114枚のままです。数字の追加面は元と異なる色・異なる数字（0〜9）をランダムに選びます。付与内容は捨て札の再利用でも保持し、対戦中は変化しません。独立付与なので＋ワイルドがない配札もあります。

|＋付きカード|On中の効果|
|---|---|
|数字|元の面／追加面のうち合法な面を選び、選んだ色・数字が場と次の判定に使われる|
|ワイルド|色指定に加え全員のOn/Offを必ず切り替え。これだけはOff中でも切り替え可能|
|ドロー2|ドロー3|
|ドロー4|ドロー攻撃を受ける手番で引かずに返し、4枚を加算して次の人へ|
|スキップ|他の3人を飛ばし、もう一度自分の手番|
|リバース|方向を反転し、その方向の次の人をスキップ|
|シールド|設置した性質を保持し、発動時Onならドローを最後の攻撃者へ反射|

Off中は通常効果。＋数字も元の面だけで出します。場に選ばれた追加面の色・数字は、後でOffになっても遡って変更しません。

## ドロー応答

エクスパンド有効ならドロー2・3・4で次の人に応答を求めます。「受ける／On中の＋ドロー4で返す」を選択。ドロー3→＋4は7枚、さらに＋4で11枚。ドロー2同士や＋なしドロー4では返せません。

返すときだけ、現在色を持っている場合も＋ドロー4を出せます。通常使用のドロー4は現在色を持っていない場合のみ。On中は数字の追加面の色も保有判定に含めます。返すカードで色を指定し、次の攻撃者はそのカードを出した人です。

「受ける」でシールドがあれば自動消費して防御。＋シールドかつ発動時Onなら累積枚数を最後の攻撃者へ返します。反射された攻撃はドロー4で返せず、シールドがあれば防御だけ可能で再反射しません。反射はその場で解決し、攻撃を受けた人の次へ通常順で進みます。反射先に通常手番の休みを追加しません。全員ドローへのシールド反射も同じ扱いで、全員ドローの使用者へ返します。

独自カードが無効でもエクスパンドは使用可能（シールド・交換・全員ドローがない構成）。エクスパンド無効は従来ルールで攻撃を即処理し、ドロー返しはありません。

## 終了と山札

最後のカードがドロー攻撃なら、返し・防御・反射が解決するまで勝者を保留。反射で手札が増えた人は勝てません。攻撃中に複数人の手札が空になれば、解決後も空のままの人のうち先に空になった人が勝者です。交換も効果処理後の手札で判定します。

山札が尽きたら場の最上段を残して捨て札を再利用。攻撃の要求枚数より少ない場合は引ける分を引いて攻撃を解決します。通常手番で全員が山札不足かつ合法手なしなら引き分け。

AIは自分の手札・場・相手の公開枚数だけを参照。追加面が必要ならそれを選び、返せる＋ドロー4があれば返す簡易方針です。最適な切り替え・反射判断やゲームバランスは保証しません。
