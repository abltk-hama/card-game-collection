# ポイント七並べ

通常の七並べとは別の独自ゲーム。自分＋AI3人、52枚・ジョーカーなし。配札は各13枚。全員の7を自動配置して所有者へ各2点を付け、♦7の持ち主から始めます。

|行動|得点|
|---|---|
|出したカードが7から連続する並びにつながる|＋2点|
|A・Kを置く、A・K側から未接続の並びを伸ばす|＋1点|
|穴を埋めて7側に接続する|その一手は＋2点。以前の得点は変更しない|
|パス|毎回－1点。出せるカードがある場合も通常は可|
|最後の1人|1枚出せる最終手番の後、残り手札1枚につき－1点|

配置は同じマークのカードの隣、または空いているA・Kです。AとKはつながりません。手札の点数表示は、その時点で出した場合の点数です。7から出したカードまでの全数字が場にあるかで＋2点を判定します。離れた並びのカードを出しても途中に穴が残れば＋1点です。

脱落・パス回数制限はありません。まだ手札のある全員が連続パスしたら強制配置に入ります。出せるカードのある人は必ず1枚出し、出せない人は－1点でパスして強制配置を次の人へ引き継ぎます。1枚配置すると連続パス数と強制配置を解除します。人数はあがった人を除いて数えます。

最後の1人になると、直ちにその人の最終手番へ移ります。合法なカードを1枚出した点数を加算してから、残り手札を減点します。最終手番にパスはできません。あがった人の全カードが場にあるため、残っている手札には必ず合法手があります。

合計点順で順位を決め、同点はあがった順を優先します。途中のあがり順は得点順位ではありません。結果画面では配置点・パス減点・残り手札減点を表示します。

AIは自分の手札と公開盤面・パス履歴だけを参照します。＋2点と自分の次のカードを開く配置を優先。＋1点しか出せず、他の人の1枚で自分の複数枚を7側から出せそうなときは一度待つことがあります。同じ盤面で再度待たず、終盤と強制配置では配置します。この待ち判断は簡易的な方針で、最適戦略を保証しません。

公平さの初回調査は [調査結果](point-sevens-fairness.md) を参照してください。
