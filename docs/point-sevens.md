# ポイント七並べ

通常の七並べとは別の独自ゲーム。自分＋AI3人、52枚・ジョーカーなし。配札は各13枚。全員の7を自動配置して所有者へ各2点を付け、♦7の持ち主から始めます。

|行動|得点|
|---|---|
|出したカードが7から連続する並びにつながる|＋2点|
|A・Kを置く、A・K側から未接続の並びを伸ばす|＋1点|
|穴を埋めて7側に接続する|その一手は＋2点。以前の得点は変更しない|
|パス|毎回－1点。出せるカードがある場合も通常は可|
|最後の1人|1枚出せる最終手番の後、残り手札1枚につき－1点|

配置は同じマークのカードの隣、または空いているA・Kです。AとKはつながりません。手札の点数表示は、その時点で出した場合の点数です。7から出したカードまでの全数字が場にあるかで＋2点を判定します。離れた並びのカードを出しても途中に穴が残れば＋1点です。

脱落・パス回数制限はありません。まだ手札のある全員が連続パスしたら強制配置に入ります。出せるカードのある人は必ず1枚出し、出せない人は－1点でパスして強制配置を次の人へ引き継ぎます。1枚配置すると連続パス数と強制配置を解除します。人数はあがった人を除いて数えます。

最後の1人になると、直ちにその人の最終手番へ移ります。合法なカードを1枚出した点数を加算してから、残り手札を減点します。最終手番にパスはできません。あがった人の全カードが場にあるため、残っている手札には必ず合法手があります。

合計点順で順位を決め、同点はあがった順を優先します。途中のあがり順は得点順位ではありません。結果画面では配置点・パス減点・残り手札減点を表示します。

AIは自分の手札と公開盤面・パス履歴だけを参照します。＋2点と自分の次のカードを開く配置を優先。＋1点しか出せず、他の人の1枚で自分の複数枚を7側から出せそうなときは一度待つことがあります。同じ盤面で再度待たず、終盤と強制配置では配置します。この待ち判断は簡易的な方針で、最適戦略を保証しません。

公平さの初回調査は [調査結果](point-sevens-fairness.md) を参照してください。

## 特殊カードとラウンド継続

各プレイヤーに5種類から独立にランダム1枚を配ります（重複あり）。前ラウンドの得点順位で最下位だった人は、通常の手札とランダム配布カードを見て追加1枚を選びます。初回の追加配布はありません。通常カードがなくなれば即あがり、残った特殊カードは失効します。

|特殊カード|効果|
|---|---|
|得点反転|全員の7側＋2／未接続＋1を＋1／＋2に交換。再使用で戻る。過去の得点は不変|
|指定配置|任意の空き位置のカードを持ち主が即配置し、その人に固定＋2点。自分のカードも指定可|
|連続配置|使用した手番は終了。次の通常手番だけ最大2枚配置。1枚目で変わった場を使って2枚目の合法性・得点を判定。1枚で終了可。パス・別特殊で失効|
|パス免除|減点なしでパス。全員パスの判定には算入|
|持ち札渡し|未終了の相手1人へ好きな通常カードを1枚渡す（0点）。相手が割り込みで任意の手札から最大1枚を通常採点で配置。辞退可・無減点、合法手なしは自動辞退。その後は渡した側の次の人から通常順へ戻る|

特殊カードは通常手番の配置前に使用し、使用で手番を終えます。強制配置・最終手番・割り込み中は使えません。割り込みは連続配置の予約や相手の通常手番を消費しません。渡した側があがって相手だけになった場合、割り込みを最終1手とし、辞退・追加の最終手番はありません。

配置されるまでに未終了の全員がパスすると強制配置になります。同じ人の繰り返しパスは人数に重複計上せず、特殊カードの手番はパス人数を増やしません。通常配置・指定配置・割り込み配置でリセットします。

結果の「次のラウンドへ」で累計を引き継ぎます。反転・予約・特殊カードはラウンドごとにリセット。終了ラウンド数や累計勝利条件は設定していません。「累計をリセットして遊ぶ」で初回に戻ります。累計は同じページを開いている間のみ保持します。

AIの特殊効果判断は自身の手札と公開盤面・相手の残枚数を参照します。相手の非公開カードを判断材料には使いません。以前の公平さ調査は特殊カード導入前の結果であり、新ルールの公平さ・特殊カードの強さは未評価です。
